# 收这吧 (ShouZheBa)

> 什么都往里丢，它替你存好、提纯、找回。
> 数据只在你的手机里，模型用你自己的 Key。

---

## 这是什么

一个安卓 App。你说一句话、转发一篇文章、记一笔小钱，它都收下：

- **一句话** → 自动判断是待办、账目还是笔记，到点提醒你
- **一篇文章** → 抓到正文、生成摘要、打上标签，以后一句话就能找回来
- **一笔小钱** → 记下来（1 块钱也值得记，因为输入成本几乎为零）

**没有服务器。没有账号。没有订阅。**你的内容不出手机，模型调用走你自己填的 API Key。

---

## 为什么做这个

市面上的工具各管一摊：滴答清单只管事、记账 App 只管钱、收藏工具只管文章。
**没有一个是"你随便丢，我来分"。**

而且它们都要上云、要订阅。这个项目的目标很具体：

> 做一个我自己天天用、数据在手里、Key 在手里、代码也在手里的工具。

### 实际验证情况

在 Android 14 模拟器上端到端跑通：

- 全新安装 → 空状态 → 录入 → 卡片出现 → 落库，全链路无崩溃
- **无 API Key 状态下**："milk15" 由规则引擎解析 → 落库账目 ¥15.00（未确认）→ 确认后 confirmed=1
- **预览与实际解析同源**：「一笔账目（¥15.00 · 其他）」与落库结果一致
- **语音链路实测**：录音启动（系统 audio_flinger 确认）→ 静音 3 秒端点检测自动停 → UI 正确反馈
- 29 个单元测试全绿（17 时间解析 + 12 规则解析）

> ⚠️ **真机（红米 K80 / HyperOS）仍需验证**：离线语音的识别准确率、云端语音的实际体验、
> 后台提醒是否到点响。这三项依赖真机系统实现。

## 怎么装

### 方式一：直接装 APK

去 [Releases](../../releases) 下载最新 APK，传到手机安装。

> **安装时若提示"未知来源"或 Play Protect 风险提示，是正常的** —— 本 App 需要自启动、
> 精确闹钟、通知等权限来保证提醒准时。确认后继续安装即可。

### 方式二：自己编译

需要 JDK 17、Android SDK（platform 35 / build-tools 35.0.0）。

```bash
git clone <repo>
cd shouzhe
echo "sdk.dir=/path/to/Android/Sdk" > local.properties
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 首次使用必做：后台设置

**这是本项目最重要的使用说明。国产 ROM 的省电策略会杀掉后台，导致提醒不响。
代码解决不了这个问题，只能手动配一次。**

### 红米 / 小米（HyperOS）

| # | 设置项 | 路径 | 目标值 |
|---|---|---|---|
| 1 | 自启动 | 设置 → 应用设置 → 应用管理 → 收这吧 → 自启动 | **开启** |
| 2 | 省电策略 | 同上页面 → 省电策略 | **无限制** |
| 3 | 通知 | 同上页面 → 通知管理 | 允许 + **设为重要** |
| 4 | 锁定后台 | 最近任务 → 下拉"收这吧"卡片 → 点锁图标 | **已锁定** |

> ⚠️ **本项目只在一台红米 K80（HyperOS）上开发与验证。**
> 其他机型未经测试。若提醒不触发，请参照上面思路自行调整后台策略（华为/荣耀、
> OPPO、vivo 的设置路径不同）。

App 内「后台运行」页面会逐项引导你完成，并显示**上次提醒的实际偏差** ——
偏差过大说明后台被限制了。

## 配置模型（BYOK）

设置页填三个字段即可，支持任何 OpenAI 兼容端点：

| 供应商 | BaseURL | 推荐模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

API Key 用 `EncryptedSharedPreferences` 加密存放，**不写日志、不上传**。

## 技术要点

| 项 | 方案 | 为什么 |
|---|---|---|
| UI | Kotlin + Jetpack Compose | 重度依赖系统能力，原生是一等公民 |
| 存储 | Room / SQLite，单库统一主表 | 四条线共享"收进来"这条主线 |
| 正文抽取 | **离屏 WebView 渲染 + 注入 JS** | HTTP 直抓微信拿不到正文（三层防御），WebView 本身就是真浏览器。见 [ADR-001](docs/adr/) |
| 提醒 | `setExactAndAllowWhileIdle` + 开机全量重排 | 排期不许出错 |
| 权限 | **最小集**，不碰短信、不碰通知监听 | 二者均为 Play 高危权限，会阻断侧载安装。见 [ADR-002](docs/adr/) |
| 模型接入 | OpenAI 兼容协议 + 三层结构化输出回退 | 一套代码适配所有供应商 |

### 三条设计铁律

1. **任何内容进来，至少留下链接。** 抓取失败也绝不丢数据，降级是主路径。
2. **记账必须二次确认。** 先落草稿，用户确认后才计入账本。错一次就失去信任。
3. **金额用整数存"分"。** 绝不用浮点 —— 对账差几分钱会让用户彻底不信这个 App。
